❓ FAQ

Frequently asked questions about GeoRestrict. Click a question to reveal the answer.

Will this block legitimate players?

It depends on your configuration. If you use ALLOWLIST mode, only players from the listed countries will be allowed in — everyone else is blocked. If you use BLOCKLIST mode, only players from the listed countries are blocked. Make sure your country list matches your intended audience. You can also grant the georestrict.bypass permission to trusted players who may be affected.

Does this work with BungeeCord / Velocity?

Yes! GeoRestrict fully supports BungeeCord, Waterfall, and Velocity proxies. Simply install the plugin on the proxy itself. When installed on a proxy, it checks connections at the proxy level before they reach any backend server.

What happens if the API is down?

GeoRestrict uses a failover system. The Cloudflare Worker gateway first tries ip-api.com and automatically falls back to ipinfo.io. If both are unavailable, the player is allowed to join by default — the plugin never blocks a player due to an API failure. Previously cached results will also continue to work during outages.

Is player data sent to third parties?

The only data sent externally is the player's IP address during a cache miss — this is required for geolocation. The request goes through a privacy-respecting Cloudflare Worker gateway. All results are cached locally on your server and never stored on any third-party service. Enable discord.maskIp to redact IPs in Discord webhooks.

How do I update the plugin?

If updateCheck is enabled in your config (it is by default), GeoRestrict will automatically check for new versions on Modrinth at startup and notify you in the console. To update, simply download the latest .jar, replace the old file in your plugins/ folder, and restart the server. Your configuration will be preserved and auto-migrated if needed.

Can I customize kick messages?

Absolutely. There are three separate kick messages in config.yml: kickMessageCountry, kickMessageASN, and kickMessageVPN. Each one can be customized to show any text you like. Color codes and formatting are supported on platforms that allow them.

How do I whitelist a specific country?

Set countryMode to ALLOWLIST and add the desired country codes to the countries list. For example, to only allow players from the US and Canada:


countryMode: "ALLOWLIST"
countries:
  - "US"
  - "CA"

Players from all other countries will be kicked with the kickMessageCountry message.

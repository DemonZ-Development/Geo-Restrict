📦 Installation

Get GeoRestrict up and running on your Minecraft server in minutes.

Requirements

  • Java 17 or newer
  • Minecraft 1.16 or newer (up to 1.26.x)

Bukkit / Paper / Spigot

  1. Download the latest GeoRestrict.jar from the Modrinth page or the official release channel.
  2. Place the .jar file into your server's plugins/ folder.
  3. Restart the server. GeoRestrict will generate a default config.yml on first launch.
  4. Configure the plugin by editing plugins/GeoRestrict/config.yml to match your needs.

BungeeCord / Waterfall

  1. Download the latest GeoRestrict.jar from the official release channel.
  2. Place the .jar file into your proxy's plugins/ folder.
  3. Restart the proxy. The default configuration will be generated automatically.
  4. Configure the plugin by editing plugins/GeoRestrict/config.yml.

Velocity

  1. Download the latest GeoRestrict.jar from the official release channel.
  2. Place the .jar file into Velocity's plugins/ folder.
  3. Restart the Velocity proxy. Configuration files will be created automatically.
  4. Configure the plugin by editing plugins/georestrict/config.yml.
ℹ️

Folia support is auto-detected at startup. No extra configuration is needed — GeoRestrict will automatically use region-aware scheduling when running on a Folia server.

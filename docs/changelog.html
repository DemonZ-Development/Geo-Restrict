📋 Changelog

Version history and release notes for GeoRestrict.

v2.0.0 Latest

  • Local IP cache for enhanced privacy — lookup results stored only on your server
  • Cloudflare Worker gateway with automatic failover (ip-api.com → ipinfo.io)
  • Folia scheduler support — auto-detected region-aware task scheduling
  • Modrinth update checker — silent version check on startup
  • Config migration system — automatic upgrades between config versions
  • New commands: /georestrict purgecache, cachestats, reload
  • georestrict.bypass permission — skip all geographic checks
  • Private subnet bypass — localhost and LAN connections always allowed
  • Discord webhook JSON formatting issue resolved
  • Compatibility range expanded to Minecraft 1.16 — 1.26.x

v1.0.0 Initial

  • Initial release of GeoRestrict
  • Country blocking with allowlist / blocklist modes
  • ASN / ISP filtering
  • VPN and proxy detection
  • Discord webhook notifications
  • Customizable kick messages
  • Multi-platform support: Bukkit, Paper, Spigot, BungeeCord, Waterfall, Velocity

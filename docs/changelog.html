📋 Changelog

What changed, in what version.

v2.1.0 Latest

2026-06-03

  • Default is now fail-closed. blockOnLookupFailure flipped from false to true. If every lookup path dies, players get kicked with kickMessageLookupFailure. Flip back if you really want fail-open.
  • Config migration no longer mangles your file. Old versions appended new keys at the bottom of the YAML, producing ugly diffs. The new migrator merges defaults into your existing structure and rewrites in place.
  • Worker requires auth when configured. If you set GATEWAY_TOKENS on the Worker, unauthenticated requests now get HTTP 401. Previously they were silently allowed.
  • Default fallback URL is https://. The previous default was http:// — your players' IPs were going in cleartext if the Worker was down.
  • Cache size cap (maxCacheEntries, default 100k). Oldest entries are evicted past the limit. Set to 0 to disable.
  • Scheduled cache purge every 6h. Expired entries are removed even if they're never read again.
  • Folia region scheduler used for sync work. Previously sync work silently ran async.
  • IPv4 CGNAT, TEST-NETs, IPv4-mapped IPv6, documentation prefix 2001:db8::/32 now treated as private.
  • Update checker compares versions numerically — 1.10 is now correctly newer than 1.9. The lexicographic fallback was a bug.
  • 19 unit tests covering private IP detection, version comparison, config loading, cache eviction, and the rule evaluator.
  • Single PluginInfo.VERSION constant. No more hardcoded "2.0.0" scattered across five files.
  • Per-platform bStats IDs (28563 / 28564 / 28565).
  • Bungee login event no longer pretends to do permission lookups that always return false.
  • Worker IPv6 validation is now strict. Previously ?ip=::::xxx would pass.
  • Discord webhook body now sets Content-Length correctly via setFixedLengthStreamingMode.
  • "Connection rejected:" prefix stripping — that was a Velocity 1.x leftover. Modern Velocity doesn't add it.
  • Committed IDE state (IntelliJ .idea/), target/, and a stray georestrict.rar from the repo.

v2.0.0 Rewrite

2026-06-03

  • Local geo_cache.json for privacy — lookup results stay on your server.
  • Cloudflare Worker gateway with provider failover (ip-api.com → ipinfo.io).
  • Folia scheduler support via reflection-based adapter.
  • Modrinth update checker on a 6h timer.
  • Config migration with a schema version field.
  • Subcommands: check, purgecache, cachestats, reload.
  • georestrict.bypass permission for trusted players.
  • Private subnet bypass for LAN/loopback.
  • Compatibility range expanded to MC 1.16 – 1.26.x.

v1.0.0 Initial

2024

  • Initial release of GeoRestrict.
  • Country blocklist / allowlist.
  • ASN filtering.
  • VPN/proxy detection via ISP keyword.
  • Discord webhook notifications.
  • Configurable kick messages.
  • Bukkit, Paper, Spigot, BungeeCord, Waterfall, Velocity support.

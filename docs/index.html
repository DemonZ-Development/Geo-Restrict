🛡️ GeoRestrict

Country, ASN and VPN blocking for Minecraft servers. Drop the jar in, set a blocklist, done.

v2.1.0 shipped. Fail-closed by default, dedup'd config migration, gateway token required when configured, real unit tests. See the changelog for the full list.
🌍

Country blocklists

ALLOWLIST or BLOCKLIST mode. ISO-3166 codes. Mixed v4/v6 supported.

📡

ASN filtering

Block specific ISPs/hosters (e.g. AS16276 for OVH) without blocking entire countries.

🕵️

VPN detection

Boolean flags from the lookup + ISP keyword fallback for when they lie.

💾

Local cache

Results cached in geo_cache.json. 30-day default TTL, atomic writes, size-capped.

📨

Discord webhooks

Get notified on block/allow. Field list is configurable. IP is masked by default.

🚀

Multi-platform

One jar. Works on Bukkit, Paper, Folia, Spigot, BungeeCord, Waterfall, Velocity.

How a connection gets checked

  1. Player connects.
  2. Local cache hit? Done.
  3. Cache miss. Plugin asks the Worker for ?ip=<addr>.
  4. Worker tries providers in the order you configured, returns the first hit.
  5. Result is cached and the rule list (country → ASN → VPN) is evaluated.
  6. First match wins. Otherwise the player joins.

No telemetry, no analytics on your players. The Worker only sees an IP, and only when there's a cache miss. See How it works for the full data flow.

Get started

Grab the latest georestrict-2.1.0.jar from the releases page, drop it into plugins/, restart, and edit plugins/GeoRestrict/config.yml. The default config blocks CN, RU, KP and IR with fail-closed behavior on lookup failure.

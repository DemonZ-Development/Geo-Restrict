⚙️ Configuration

Complete reference for the config.yml file. Every option explained.

config.yml

config.yml 
# GeoRestrict configuration
configVersion: 2

# Country filtering
countryMode: "BLOCKLIST"   # BLOCKLIST or ALLOWLIST
countries:
  - "CN"
  - "RU"

# ASN / ISP filtering
asnMode: "DISABLED"       # BLOCKLIST, ALLOWLIST, or DISABLED
asns:
  - "AS12345"

# VPN / Proxy detection
vpnCheckEnabled: true
vpnKeywords:
  - "hosting"
  - "vpn"
  - "proxy"
  - "datacenter"

# Kick messages
kickMessageCountry: "You are not allowed to join from your country."
kickMessageASN: "Your ISP/ASN is not permitted."
kickMessageVPN: "VPNs and proxies are not allowed."

# Cache & network
cacheTtlDays: 7
updateCheck: true
connectionTimeoutMs: 5000

# Discord webhook
discord:
  webhook: ""
  maskIp: true
  title: "GeoRestrict Alert"
  color: "#FF5555"
  fields:
    - name: "Player"
      value: "%player%"
    - name: "Status"
      value: "%status%"
    - name: "IP"
      value: "%ip%"
    - name: "Country"
      value: "%country%"
    - name: "ASN"
      value: "%asn%"
    - name: "ISP"
      value: "%isp%"
    - name: "Reason"
      value: "%reason%"

Field Reference

Field Type Default Description
configVersion Integer 2 Internal version number for config migration. Do not change manually.
countryMode String BLOCKLIST Set to BLOCKLIST to block listed countries, or ALLOWLIST to only allow them.
countries List [] List of ISO 3166-1 alpha-2 country codes (e.g. US, DE, CN).
asnMode String DISABLED Set to BLOCKLIST, ALLOWLIST, or DISABLED.
asns List [] List of ASN identifiers (e.g. AS12345).
vpnCheckEnabled Boolean true Enable or disable VPN / proxy / hosting detection.
vpnKeywords List [hosting, vpn, proxy, datacenter] Keywords matched against the ISP/org field to detect VPN/proxy usage.
kickMessageCountry String — Message shown to players kicked for country restrictions.
kickMessageASN String — Message shown to players kicked for ASN/ISP restrictions.
kickMessageVPN String — Message shown to players kicked for using a VPN or proxy.
cacheTtlDays Integer 7 Number of days to keep cached IP lookup results before refreshing.
updateCheck Boolean true Check Modrinth for plugin updates on startup.
connectionTimeoutMs Integer 5000 HTTP timeout (ms) for IP lookup API requests.
discord.webhook String "" Discord webhook URL. Leave empty to disable webhook notifications.
discord.maskIp Boolean true Partially mask player IP addresses in Discord messages for privacy.
discord.title String GeoRestrict Alert Title of the Discord embed message.
discord.color String #FF5555 Hex color for the Discord embed sidebar.
discord.fields List — Custom fields for the Discord embed. Each field has a name and value.

Placeholders

The following placeholders can be used in Discord webhook fields:

Placeholder Description
%player% The player's username
%status% Connection status (e.g. BLOCKED, ALLOWED)
%ip% Player's IP address (masked if maskIp is enabled)
%country% Detected country code
%asn% Detected ASN identifier
%isp% Detected ISP / organization name
%reason% Reason for the block (country, ASN, or VPN)

💻 Commands & Permissions

All available commands and their required permissions.

Commands

Command Permission Description
/georestrict — Show plugin info & credits
/georestrict check <ip|player> georestrict.admin Look up geographic and network data for an IP or online player
/georestrict purgecache georestrict.admin Clear the entire local IP lookup cache
/georestrict cachestats georestrict.admin Show cache statistics (entries, hit rate, size)
/georestrict reload georestrict.admin Reload config.yml without restarting the server

Permissions

Permission Default Description
georestrict.admin OP Grants access to all admin sub-commands (check, purgecache, cachestats, reload)
georestrict.bypass false Bypass all geographic, ASN, and VPN checks. The player will never be kicked by GeoRestrict.
💡

Give the georestrict.bypass permission to trusted staff or whitelisted players who may connect from restricted regions or through VPNs.

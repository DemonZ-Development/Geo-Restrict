# GeoRestrict assets

These are the public brand and interface assets for repository pages, server
marketplaces and the project wiki.

| File | Size | Intended use |
|---|---:|---|
| `georestrict-banner.png` | 2400 × 960 | Repository header and marketplace banner |
| `georestrict-icon.png` | 1024 × 1024 | Square project icon for Modrinth and other listings |
| `georestrict-logo.png` | 2400 × 800 | Wide logo for layouts that do not need the full banner |
| `ui-icons.svg` | Vector sheet | Interface icons used by the documentation site |

The PNG files are the original full resolution raster exports. The copies in
`docs/assets/` are retained because that directory is deployed directly to
Cloudflare Pages.
